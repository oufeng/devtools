## Agent skills

### Issue tracker

Issues live as local markdown files under `.scratch/<feature-slug>/` (no online tracker). See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary, recorded as `Status:` lines in issue files. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
